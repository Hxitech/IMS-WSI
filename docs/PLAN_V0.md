# V0 开发计划（可跑通的最小闭环）

目标：在本地磁盘存储条件下，跑通“上传切片/附件 → 入库任务 → 元数据入库 → 列表检索 → viewer 浏览 → 采图保存”的最小链路。

## 里程碑
### M0. 项目骨架与环境
- 后端 FastAPI 项目骨架、配置、日志
- 前端 Vue 项目骨架
- 本地开发启动脚本

### M1. 元数据模型（最小）
- 病例 Case
- 切片 Slide
- 附件 Attachment
- 入库任务 Task
- 分享 ShareToken（可选）

### M2. 上传与入库
- 分片/断点续传（可先简化为普通上传，后续增强）
- 入库任务创建、状态流转
- 任务中心（最小版：待分配/已分配）

### M3. OpenSlide 验证与预览
- 对可读格式进行 openslide 读取验证
- 抽取基础元信息（level count、dimensions、mpp(如有)）
- 生成缩略图（thumbnail）
- Viewer 页面可打开并展示（先用缩略图/静态预览，后续做 tile）

### M4. 标签识别（最小版）
- 文件名识别规则（去后缀）
- OCR/条码/二维码在 V0 可先 stub（占位）

### M5. 采图（最小版）
- 前端局部截图（canvas）
- 保存采图图片 + 倍率字段

- 文档：SRS v0.1（已出）、架构图（已出）、V0 计划、API 草案、数据字典
- 代码：后端/前端可启动，可演示最小闭环
